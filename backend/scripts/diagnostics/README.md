# Diagnóstico operativo

Herramientas manuales para inspeccionar el funcionamiento del backend:

- `analizar_respuestas.py`: ejecuta una batería demostrativa de consultas.
- `inspeccionar_base_datos.py`: revisa relaciones de diagnósticos y usuarios.
- `listar_diagnosticos.py`: lista diagnósticos persistidos.
- `probar_diagnostico.py`: consola interactiva para demostraciones.

Se ejecutan desde `backend/`, por ejemplo:

```powershell
..\.venv\Scripts\python.exe scripts\diagnostics\probar_diagnostico.py
```
