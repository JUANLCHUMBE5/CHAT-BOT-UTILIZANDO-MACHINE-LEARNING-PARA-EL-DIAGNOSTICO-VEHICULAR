# Scripts del monorepo

Puntos de entrada que coordinan más de un módulo:

- `iniciar_carbot.ps1`: inicia backend, frontend y el túnel de WhatsApp.
- `verificar_proyecto.ps1`: valida backend, frontend y harnesses.

Los scripts exclusivos del backend viven en `backend/scripts/`; los de
entrenamiento viven en `machine_learning/training/`.
