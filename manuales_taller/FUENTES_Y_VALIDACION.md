# Estado de la base de conocimientos RAG

Los procedimientos de `manual_procedimientos.txt` son una base preliminar de apoyo y
no se consideran instrucciones oficiales de fabricante. Actualmente no existe un
registro completo de marca, modelo, año, motor, documento, edición y página para cada
valor técnico.

Por seguridad, CarBot conserva separadas la confianza ML y la similitud RAG y exige
revisión humana cuando usa este corpus. No se debe presentar un torque, presión,
secuencia de desmontaje ni procedimiento de alto voltaje como especificación oficial
hasta completar el registro siguiente para cada sección:

- código estable del procedimiento;
- fabricante, modelo, año y motorización aplicables;
- título y edición del manual OEM;
- número de página o sección;
- archivo o URL autorizada;
- fecha y mecánico responsable de la validación;
- estado: `borrador`, `validado` o `retirado`.

Los archivos OEM con restricciones de licencia deben almacenarse fuera de Git. En el
repositorio solo debe conservarse la referencia y una síntesis autorizada.
