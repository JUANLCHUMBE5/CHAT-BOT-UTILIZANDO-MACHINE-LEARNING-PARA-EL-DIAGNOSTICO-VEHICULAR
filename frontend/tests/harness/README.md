# Harnesses del frontend

Pruebas ligeras de contratos y reglas que no necesitan abrir el navegador:

- `routing.harness.js`: navegación y permisos por rol.
- `profile-edit.harness.js`: contrato de edición de perfiles.

Se ejecutan mediante `npm run test:harness` o junto con toda la verificación
del frontend mediante `npm run verify`.
